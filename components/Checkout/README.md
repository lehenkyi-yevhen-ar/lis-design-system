# Checkout

Оформлення: кроки (`.steps`), групи полів у картках (`.form-section` з `h4`), спосіб доставки картками-опціями (`.option-card` з радіо), наші `Select` і `DatePicker`, підсумок, що прилипає (`.summary`, sticky top 96px).

`.checkout` — 1fr / 400px, на планшеті одна колонка. Перевірка при натисканні «До оплати»: помилки на полях + `Toast`, фокус на першому полі з помилкою; кнопка показує `is-loading`.
