# Button

Кнопка дії: шість варіантів, три розміри, усі стани. Клас `.btn` + варіант `.btn--primary | --secondary | --accent | --outline | --ghost | --danger`.

## Використання
- Одна `btn--primary` на екран або секцію. Вторинна дія того ж рівня — `btn--secondary` (коричнева) або `btn--outline`.
- `btn--accent` (теракота) — лише промо й маркетингові CTA.
- `btn--danger` — тільки для незворотних дій і завжди з підтвердженням у `Modal`.
- Розміри: `btn--sm` (36px, тільки щільні таблиці й тулбари), базовий 44px, `btn--lg` (52px, hero й оформлення). Зона натиску ≥44×44.
- Іконка: інлайн SVG першою дитиною (`gap: space-2`). Кнопка-іконка — `btn--icon` + обов'язковий `aria-label`; кругла — `btn--round`.
- Стани: `:disabled`, `.is-loading` (спінер, текст ховається). `.is-hover/.is-active/.is-focus` — лише для документації.
- Hover прозорих і контурних кнопок — скляна «крапля» (`glass-hover`, `glass-spec`).
- Усередині капсули (навбар, тулбар) додайте контейнеру `.pill-group`: кнопки стануть капсулами.
- Текст — дієслово: «Зберегти», «Оформити замовлення», а не «ОК».

## Що дає споживач
Текст або іконку, `type`, обробник. Шрифт — `label` (KyivType Sans 600), ніколи Ermilov.
