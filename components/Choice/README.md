# Choice

Чекбокс, радіо й перемикач на нативних `input` з власним виглядом: `.choice` > `input.check | .radio | .switch` + текст.

- Чекбокс — кілька незалежних виборів або згода; `indeterminate` для «вибрати всі».
- Радіо — один з 2–5 видимих варіантів; більше — `Select`; варіанти з ціною й описом — картки-опції (`.option-card`, див. Checkout).
- Перемикач (`role="switch"`) діє одразу. Якщо потрібна кнопка «Зберегти» — це чекбокс.
- Підпис другого рядка — `<small>`. Вимкнений стан — `opacity .45`. Помилка групи — `.is-error` на контейнері.
