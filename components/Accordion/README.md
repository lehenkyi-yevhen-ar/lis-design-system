# Accordion

Список питань з відповідями, що розгортаються (FAQ, характеристики). `.acc[data-acc]` > `.acc__item` > `button.acc__btn` + `.acc__panel > div > p`.

- `data-acc="single"` — одночасно відкрита одна відповідь; без значення — будь-скільки. Відкритий за замовчуванням — `.is-open`.
- «Плюс» у колі плавно стає «мінусом» на заливці `color-primary`; висота анімується (grid-rows), `duration-slow`.
