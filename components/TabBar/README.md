# TabBar

Нижня навігація для телефона: скляна капсула внизу екрана з 3–5 розділами верхнього рівня, як у застосунках iOS 26. `nav.tabbar.glass` > `a.tabbar__item` (іконка + підпис).

- Активний розділ — `aria-current="page"` (скляна «крапля» `glass-thumb`, іконка `color-primary`). Підпис видно завжди: іконка без тексту нечитна. Лічильник — `.tabbar__badge` (accent) із `aria-label`.
- `position: fixed` унизу, відступ `12px + var(--safe-bottom)`, `z-sticky`. Капсула `radius-full`, пункти всередині теж капсули (концентрично). Висота пункту 52px — понад зону натиску 44px (`--touch-target`).
- Додайте `.has-tabbar` на `body`: нижній відступ `--tabbar-height + --safe-bottom`, щоб останній блок не ховався під капсулою. Якщо `.tabbar--mobile` лежить прямо в `body`, відступ додається сам і лише на телефоні. Тости, шторки й модалки піднімаються над tabbar самі.
- `.tabbar--mobile` — показувати лише до 640px (на десктопі працює `Navbar`). `.tabbar--static` — не фіксувати (макети, превʼю).
- Не більше 5 пунктів; п'ятий може бути «Ще» зі шторкою `Modal` для рідкісних розділів. Одна дія «створити» — це кнопка на екрані, а не вкладка. Назви — один іменник: «Каталог», «Кошик».
- Клавіатура й екранні читачі: це звичайні посилання; роутер ставить `aria-current` сам.
