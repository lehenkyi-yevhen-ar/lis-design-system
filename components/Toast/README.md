# Toast

Скляне сповіщення внизу праворуч (на телефоні — по центру). Викликається з коду: `DS.toast({type, title, text, action, duration})`.

- Типи `success | error | warning | info` з іконкою й кольором статусу; заголовок — що сталося, текст — деталь.
- 5 секунд за замовчуванням, таймер зупиняється при наведенні чи фокусі; `duration: 0` — лише для помилок, що потребують дії.
- Дія: `action: {label: 'Скасувати', onClick}` — для зворотних операцій (видалення з кошика).
- Не більше 4 одночасно; `role=status` (помилка — `alert`), контейнер `aria-live=polite`.
