# Tooltip

Скляна підказка до іконки чи терміна: атрибут `data-tip="…"` (+ `data-kbd="E"` для клавіші) на будь-якому елементі.

- З'являється через 350 мс після наведення або одразу при фокусі; Esc ховає; біля верхнього краю — знизу.
- Лише доповнює: на телефоні hover немає, тож важливе не ховаємо в підказку. Кнопці-іконці все одно потрібен `aria-label`.
