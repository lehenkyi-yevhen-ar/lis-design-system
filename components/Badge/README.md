# Badge

Статус одним-двома словами. На бейдж не клікають — для клікабельних є `Tag`.

- `.badge` + тон `--brand | --success | --warning | --error | --info | --accent`; м'який фон — 18%/14% тону (`--soft-mix`).
- `.badge--dot` — для таблиць і списків; `.badge--solid` — один акцент на картці товару; `.badge--count` — лічильник.
- Статус завжди словом, не лише кольором.
