# Link

Текстове посилання: колір `color-accent-text`, підкреслення 1px з відступом 3px, при наведенні 2px.

- `.link` — у тексті; `.link--quiet` — футер, метадані (колір тексту, лінія `color-border-strong`).
- Підкреслення не прибирати: колір сам по собі не розрізняють люди з порушенням кольоросприйняття.
- Дія, а не перехід → `Button` з `btn--ghost`.
