# ProductSection

Секція каталогу: `.section__head` (eyebrow + `h1`-заголовок великими + посилання «Усі»), фільтри-теги (`.filters`), `.product-grid` (4 → 2 → 1 колонки), «Показати ще» (`.more`).

Відступ секції — `space-section`; між заголовком і сіткою — `space-10`. Додавання в кошик — `Toast` з дією «Відкрити кошик».
